# 公开灵感墙设计说明

## 目标

创建一个无需登录即可匿名提交建议的单页网站。页面需要在第一屏明确说明用途，让访客立即理解“写下一条想法并公开分享”，并通过活跃、可视化的评论墙降低参与门槛。

当前版本是可直接打开运行的前端原型：评论保存在浏览器本地。数据访问逻辑必须与界面逻辑分离，并预留远程 API 配置入口，后续接入 Supabase、Firebase 或自有服务时无需重做页面。

## 视觉方向

采用“灵感发射台”风格：温暖米白底色配合紫色、珊瑚橙和亮黄色强调色；使用大号标题、圆角投稿卡片、轻量网格背景和不规则彩色装饰，营造友好、年轻但不过度游戏化的氛围。

第一屏包含品牌标识、简短导航、核心文案、匿名建议输入区和参与数据。输入框与主要按钮必须是视觉焦点。页面下半部分是公开灵感墙，以响应式卡片网格展示建议。

## 页面组成

### 顶部导航

- 品牌名“点子发射站”与简洁图形标识。
- “浏览灵感”锚点链接。
- “发布想法”按钮，点击后聚焦投稿输入框。

### 首屏投稿区

- 主标题强调“一个想法，也许就是下一个小程序”。
- 一句话说明页面用途与匿名规则。
- 大型多行输入框，只收集建议内容，不要求昵称或登录。
- 显示当前字数与 280 字上限。
- 发布按钮在空内容时不可用；有效内容提交后给出明确成功反馈。
- 展示灵感总数、今日新增数和累计点赞数，帮助形成参与感。

### 灵感墙

- 搜索框支持按建议正文过滤。
- 分类筛选包含全部、效率工具、生活服务、学习成长、社交娱乐；用户不需要手动选分类，前端依据关键词做轻量自动归类，无法判断时归入“其他灵感”。
- 排序支持“最新发布”和“最多赞同”。
- 评论卡片展示分类、相对发布时间、正文和点赞按钮。
- 提供数条高质量初始示例，让首次打开页面时也能看到完整效果。
- 搜索或筛选无结果时显示友好的空状态及清除筛选按钮。

### 页脚

- 简要说明当前是公开创意收集页面。
- 标明匿名提交原则，并提示不要填写敏感个人信息。

## 交互与动效

- 发布成功后，新卡片插入灵感墙顶部并短暂高亮，表单清空，统计数字同步更新。
- 点赞按钮具有按压反馈；同一浏览器可再次取消点赞，避免无限重复计数。
- 页面元素进入视口时使用轻微上移动画；尊重 `prefers-reduced-motion`，系统要求减少动态时关闭非必要动画。
- 桌面端为双栏首屏和三列卡片墙；平板为两列；手机为单列，所有交互控件保持足够触控尺寸。

## 技术结构

使用三个现有文件，不引入构建工具或外部依赖：

- `Core_Thinking.html`：语义化页面结构、表单、筛选控件和无障碍提示区域。
- `Core_Thinking.css`：设计变量、响应式布局、卡片样式、动效与无障碍状态。
- `Core_Thinking.js`：状态管理、渲染、筛选排序、点赞、表单校验和数据适配层。

JavaScript 中的数据适配层提供 `listIdeas`、`createIdea` 和 `toggleLike` 三个异步方法。默认实现使用 `localStorage`。保留远程 API 基础地址配置；配置后可以将方法替换为 `fetch` 请求，而调用它们的界面代码保持不变。

## 数据模型

每条建议包含：

- `id`：唯一字符串。
- `content`：清理前后空白后的建议正文。
- `category`：自动识别的分类。
- `createdAt`：ISO 时间字符串。
- `likes`：非负整数。
- `liked`：当前浏览器是否已点赞。

## 数据流

1. 页面加载时从数据适配层读取评论；本地无数据时写入初始示例。
2. 状态层保存完整列表、查询词、分类和排序方式。
3. 渲染函数根据状态生成统计数字和评论卡片。
4. 发布时先在表单层校验，再调用 `createIdea`，成功后更新状态并渲染。
5. 点赞时调用 `toggleLike`，成功后更新对应卡片与统计数字。
6. 将来接入真实后端时，由服务端负责持久化、公共可见性、频率限制和内容审核。

## 异常与安全边界

- 使用 DOM `textContent` 写入用户内容，禁止将评论正文拼接为 HTML，避免脚本注入。
- 拒绝空白内容和超过 280 字的内容。
- `localStorage` 读取失败或内容损坏时回退到初始数据，并展示非阻塞提示。
- 数据写入失败时保留输入内容并提示稍后重试。
- 当前静态版本不能让不同设备共享评论；页面与文档均不声称已经具备真实跨用户公开存储。上线前需要接入服务端，并增加内容审核、限流和滥用举报能力。

## 验收标准

- 直接打开 `Core_Thinking.html` 即可正常使用，无需安装依赖。
- 空内容无法发布；1 至 280 字建议可以发布并在刷新后保留。
- 搜索、分类、最新/最热排序和点赞均可工作。
- 在常见手机和桌面宽度下无横向滚动，表单与评论卡片保持清晰。
- 键盘可以访问所有按钮和表单控件，焦点状态清楚，动态提示可被辅助技术读取。
- 用户内容以纯文本渲染，不执行 HTML 或脚本。
- 清除本地存储或首次访问时仍有完整的示例内容与空状态处理。
