# 电脑端与手机端响应式优化设计

## 目标

让同一个 `Core_Thinking.html` 页面在电脑、平板和手机上自动适配，无需维护独立手机版。删除页脚中的“当前为前端体验版 · 评论保存在本浏览器 · 接入公开 API 后可实现跨用户共享”文字，同时保留页面其他功能与数据逻辑。

## 方案

沿用现有 HTML 结构和 CSS 设计系统，通过分级断点调整排列方式、尺寸、间距与触控区域：

- 大于 1080px：首屏双栏，灵感墙三列。
- 841px 至 1080px：首屏保持双栏但收紧间距，灵感墙两列。
- 641px 至 840px：首屏改为单栏，投稿卡片位于介绍内容下方。
- 640px 及以下：所有主体内容使用单列，工具栏纵向排列，评论墙单列。
- 410px 及以下：进一步收紧页边距与统计区间距，确保窄屏无横向滚动。

## 组件调整

### 页脚

- 从 HTML 中删除指定的体验版说明段落。
- 电脑端保留品牌与一句品牌说明，左右排列。
- 手机端改为纵向居中排列，减少底部占用空间。

### 手机首屏

- 保持标题和投稿框的内容顺序，将双栏布局切换为单栏。
- 标题使用流体字号，避免换行后超出屏幕。
- 投稿框占满内容宽度，装饰元素不得扩大页面滚动宽度。
- 统计数据等宽分布，标签允许换行但不重叠。

### 手机灵感墙

- 搜索框、分类筛选与排序控件纵向排列。
- 分类筛选允许在控件内部横向滑动，不使整个页面产生横向滚动。
- 评论卡片使用单列；正文、标签和点赞按钮在长内容下保持可读。
- 发布、点赞、筛选和排序等主要控件具备至少 44px 的触控高度。

### 底部行动区

- 电脑端保持文案与按钮横向排列。
- 手机端改为上下排列，按钮占满宽度。

## 数据与错误处理

本次不修改数据模型、`localStorage` 适配层、远程 API 预留接口或评论交互逻辑。布局调整不得影响发布、刷新保存、搜索、筛选、排序与点赞。用户输入仍以纯文本渲染。

## 验证标准

- 页脚不再出现指定的体验版说明文字。
- 在 1440px、768px 和 390px 视口下页面无横向滚动。
- 电脑端显示双栏首屏与三列灵感墙；手机端显示单栏首屏与单列灵感墙。
- 390px 视口下按钮、输入框、筛选和排序均可直接触控使用。
- 三种视口下均能完成发布、搜索、分类筛选、最新/热门排序和点赞。
- 浏览器控制台无页面脚本错误。
